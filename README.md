# PFA-VR — Aplikasi Terapi WebXR

> Aplikasi WebXR Psychological First Aid berisi 7 sesi terapi terpandu, dirancang untuk headset Meta Quest dan dapat berjalan penuh secara offline.

## ✨ Fitur

- 7 sesi terapi terpandu
- 3 jalur interaksi: gaze, controller, hand-tracking
- Mode offline penuh (PWA)
- Panel kontrol dari laptop lewat WebSocket
- Subtitle dan ambience per scene
- Hand-tracking komponen raw-hands buatan sendiri

## 🛠 Tech Stack

"A-Frame 1.8" "Vite" "PWA" "WebSocket" "edge-tts" "JavaScript"

## 🚀 Menjalankan

```
npm install
npm run dev
npm run build  # hasil statis, bisa di-hosting apa saja
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
