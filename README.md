# PFA-VR — Psychological First Aid WebXR

[![Build WebXR](https://github.com/hilman-devop/pfa-vr/actions/workflows/build.yml/badge.svg)](https://github.com/hilman-devop/pfa-vr/actions/workflows/build.yml)
> Prototipe Psychological First Aid berbasis WebXR dengan tujuh sesi terpandu untuk headset VR dan browser desktop.

**Stack:** A-Frame · Vite · WebXR · PWA

## Ringkasan

Prototipe Psychological First Aid berbasis WebXR dengan tujuh sesi terpandu untuk headset VR dan browser desktop.

## Fitur utama

- 7 sesi terapi terpandu
- Gaze, controller, dan hand-tracking
- Mode offline melalui PWA
- Subtitle dan ambience per scene
- Panel kontrol laptop melalui WebSocket
- Build statis untuk deployment web

## Menjalankan secara lokal

~~~bash
npm install
npm run dev
npm run build
~~~

## Keamanan dan batasan

Prototipe teknologi, bukan alat diagnosis atau pengganti psikolog. Review profesional diperlukan sebelum penggunaan lapangan.

Jangan commit API key, password, token, session ID, data pribadi, atau credential deployment.
